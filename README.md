# Blink Arena

Top-down аркадный шутер на pygame-ce (учебный проект). Выжить в комнате, используя blink.
Спецификация и этапы разработки: см. промпт проекта (11 этапов).

## Запуск

```
pip install -r requirements.txt
python main.py              # случайная комната
python main.py --room 3     # конкретная комната (1-5)
python -m pytest            # тесты (работают без окна)
```

## Управление (по умолчанию)

| Действие | Клавиши |
|---|---|
| Движение | WASD |
| Стрельба (автоогонь, 8 направлений) | стрелки; диагональ = две стрелки |
| Blink | Space (с этапа 5) |
| Перезапуск комнаты | R |
| Отладка (сетка тайлов) | F1 |
| Выход (до появления меню) | Esc |

## Структура

`config.py` параметры (`cfg.X`) · `main.py` окно, цикл 60 Гц, состояния · `input.py` привязки действий ·
`entities.py` / `world.py` данные мира · `simulation.py` порядок тика · `physics.py` движение, коллизии, raycast, sweep · `room.py` загрузка и валидация комнат ·
`renderer.py` вся отрисовка · `ui.py` HUD · `rooms/room_NN.txt` комнаты (ASCII) · `tests/`.

## Состояние

Готовы этапы 1-4: окно и цикл 60 Гц, 5 комнат с валидатором, коллизии круг-тайлы, движение
с заносом, автоогонь с пулями (sweep против стен и врагов), расталкивание кругов (игрок-враг,
враг-враг; проявляющиеся враги не твёрдые). Враги пока неподвижные заглушки с HP; убитые удаляются, зачистка комнаты появится на этапе 9.
